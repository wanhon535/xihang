关于汐航 TideSail

汐航是云南汐构信息技术有限公司出品的企业数字化办公效率中枢。我们不做又一套需要全员重新学习的系统，而是给企业已有的系统加一层入口、一层数据、一层权限。

我们解决什么问题

中小企业的信息化通常不是「没有系统」，而是系统太多、入口太散、数据太碎。员工每天在多个后台之间切换，管理者要挨个问进度，财务月底靠人肉合并表格。

汐航的四个模块对应四类日常损耗：

  • 统一应用入口 + SSO 单点跳转——解决「找系统、记密码」。星钥库集中托管各系统凭证，按权限取用。
  • 申请中心——同步钉钉审批流，解决「翻审批、看进度」。
  • 项目成本台账——全员记账、多凭证留存、按项目汇总，解决「记流水、对不上」。
  • 企业知识库——制度、模板、对接资料集中沉淀，解决「资料跟着人走」。

产品边界：我们不做什么

说清边界比罗列功能更有用，能帮你判断我们是否适合。

需求汐航是否覆盖说明
统一入口、应用导航、SSO✅ 核心能力支持应用分组、按角色可见、单点跳转、凭证托管
钉钉审批同步与汇总✅ 核心能力不替换钉钉审批，做同步、归集与状态视图
项目成本台账与凭证✅ 核心能力按项目归集、一条记录多张凭证、项目维度概览
企业知识库✅ 核心能力全员可用，按目录组织与检索
对外 API 与令牌管理✅ 支持带权限范围的令牌、调用日志
公文流转、用印、人事档案全流程❌ 不做属于传统 OA / HR 系统范畴，建议选择专业产品
行业深度流程（工单、HIS、教务等）❌ 不做建议选择行业垂直系统，汐航可作为统一入口接入
法定会计核算与报税❌ 不做成本台账是管理会计工具，不替代财务软件

适合谁

20–200 人、已经有多个独立系统、希望用较低改造成本把入口与数据收拢的中小企业。典型决策人是 IT / 信息化负责人、行政人事负责人、财务或项目负责人。

如果你的团队少于 20 人，钉钉原生审批加一个简单入口页通常已经够用；如果团队超过数百人且有完整行政体系，传统 OA 平台更合适。这些情况下我们不会建议你采购汐航。

数据与合规

  • 部署位置：系统部署在境内服务器，通过 HTTPS 访问。
  • 备案信息：域名 xigouoa.xyz 已完成 ICP 备案，备案号 滇ICP备2026021477号-1，备案主体为云南汐构信息技术有限公司。
  • 账号与权限：支持组织内账号体系与钉钉扫码登录；系统内按角色区分管理员与普通成员，各模块分别授权。
  • 凭证管理：星钥库集中托管系统凭证，按权限取用；对外调用需通过带权限范围的 API 令牌，并保留调用日志。

开通方式

  1. 已有账号的成员：直接打开登录页，使用密码或钉钉扫码登录，即可进入工作台。
  2. 新企业接入：由云南汐构信息技术有限公司开通组织账号，再按团队成员分配账号与权限。请通过你与汐构的现有对接渠道联系；开通后由管理员统一分配成员账号。
  3. 落地建议：先接入高频系统并跑通统一入口，再逐步推进审批汇总、成本台账与知识库。选型指南里有分阶段的验收标准。
