项目成本台账怎么记

从字段设计、凭证留存到月度核对，给财务和项目负责人一套可以直接照抄的结构，让每一笔支出都能对上凭证。

云南汐构信息技术有限公司 发布于 2026-10-24 约 13 分钟阅读

一、先明确：台账是给谁看的

同一笔支出，财务、项目负责人、老板想看的东西不一样。台账设计失败的根源，往往是试图用一张表满足三种视角。

角色关心什么对台账的要求
财务钱花得合不合规、票据齐不齐、能不能对账凭证完整、金额准确、有唯一标识
项目负责人这个项目投入多少、花在哪、还剩多少预算按项目归集、按分类拆分、实时可看
经营者哪类项目赚钱、成本结构是否失控跨项目汇总、按时间趋势对比

三者可以共用一份明细，只要字段设计得当：明细足够细，视图各自不同。反过来，如果每个角色各维护一张表，月底必然对不上。

二、台账字段设计：最小可用集合

字段不是越多越好。下面 11 个字段覆盖了 90% 的核对需求，多出来的字段通常没人填。

字段作用填写要求
发生日期归属期间按实际支付或权责发生日期，不要填录入日期
项目归集维度必填，且必须是已存在的项目，不允许手写新项目名
分类成本结构用固定枚举（人力、外包、广告、差旅、采购、其他），不允许自由输入
金额核算基础数值型，不带货币符号；外币另记原币与汇率
币种避免混算没有该字段时，必须在备注写清原币
供应商 / 收款方查重与审计写实际收款主体，不写个人昵称
支付方式对银行流水对公转账 / 支付宝 / 微信 / 现金 / 信用卡
凭证证明力发票、收据、支付截图、合同，一条记录可挂多张
唯一标识防重复发票号或支付流水号，用于查重
经办人责任追溯实际花钱的人，不是记账的人（可以是同一人）
备注解释异常缺票原因、汇率来源、特殊约定

关键原则：分类和项目必须是「选」而不是「写」。自由输入是台账数据失真的第一大来源——「广告费」「广告投放」「推广费」会变成三个分类，月底汇总时没人知道它们是不是一回事。

三、凭证留存：三条硬规则

  1. 一笔记账，对应一张（或一组）可追溯的凭证。凭证不是「以后补」，补的时候往往已经想不起当时的情况。
  2. 截图要能看清四件事：金额、收款方、时间、订单号/流水号。只有金额的截图在审计时等于没有。
  3. 凭证与记录放在一起，不要存在个人手机相册。存在个人设备里的凭证，在人员变动时会直接消失。

实操上，手机支付截图是最常见的凭证类型。建议在支付完成的当天就录入，因为此时截图还带着完整信息，回忆成本最低。

四、月度核对：四步，不超过两小时

  1. 对总额。台账本月支出合计 vs 银行 / 支付宝 / 微信流水合计。差异要先解释，再调整。
  2. 对凭证。筛出无凭证记录，逐条补齐或标注原因。目标是无凭证记录占比低于 5%。
  3. 对项目。检查是否有支出挂在「未分配 / 其他」项目下。这类记录超过 10%，说明录入时偷懒了，成本结构已经失真。
  4. 对重复。按「唯一标识」与「金额 + 日期 + 收款方」双口径查重，删掉重复录入（保留原始记录并标注，不要直接物理删除）。

这四步做完，台账就从「流水」变成了「可以决策的数据」。

五、多人记账的两条防错设计

1. 按项目授权，而不是全员全项目

让每个人都记所有项目，重复率会飙升。正确做法是每个项目指定 1–2 名记账人，其他人只读。这样责任清晰，也符合「谁经手谁记录」的原则。

2. 录入即查重

在录入界面就按唯一标识或「金额 + 日期 + 收款方」提示疑似重复，而不是等到月底人工比对。查重放在录入时，成本最低。

六、Excel 还是系统：什么时候该换

场景Excel 够用建议换系统
记账人数1–2 人3 人以上，且分散在不同地点
项目数量5 个以内10 个以上，或项目频繁增减
凭证凭证少、可集中存放凭证以截图为主、需要与记录绑定
权限不需要区分可见范围需要按项目 / 角色控制可见
并发不会同时编辑多人同时录入（Excel 共享文件会冲突、覆盖）

Excel 最大的隐性成本不是功能，而是版本冲突：两个人同时编辑一个共享文件，后保存的会覆盖先保存的内容，而且没有任何提示。当记账人数超过 2 人，这个风险就开始变得不可接受。

七、汐航的成本台账怎么做

  • 全员记账：管理员共享台账，成员按项目登记支出，不需要每人维护一份文件。
  • 项目与分类可选：从下拉选择，避免同义分类；支持按分类、项目筛选与多选。
  • 一条记录多张凭证：发票、支付截图可一次挂多张，图片自动压缩转存，不会因为体积超限存不进去。
  • 项目维度概览：直接看各项目投入总额与结构，不用再手工合并表格。
  • 与审批同一入口：审批通过后的支出在同一个工作台登记，审批与钱能对上，见审批流程线上化。
项目成本台账和会计账簿是什么关系？

成本台账是管理会计工具，不是法定会计账簿。它按项目维度归集支出，用于看投入结构、算项目毛利、支撑报价决策；法定账簿仍由财务按会计准则记录。两者应当能对账，但不能互相替代。

多人一起记账，怎么避免重复和遗漏？

三条规则：每笔支出必须有唯一标识并在录入时查重；按项目授权，谁负责哪个项目谁记账；每周固定核对新增记录与凭证数量，不要等到月底。

没有发票的支出要不要记？

要记，但必须标注凭证类型。管理台账的目的是反映真实的成本发生，缺票不等于没花钱。建议把凭证类型做成枚举：发票、收据、支付截图、合同、其他，并在备注写明缺票原因。

外币支出怎么记？

不要凭印象折算。记录原币金额、币种与发生日期，按企业会计政策确定的汇率折算为本位币，并把汇率来源写进备注。台账没有币种字段时，至少要在备注中写清原币与汇率。
