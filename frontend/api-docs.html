汐航 API 文档

用 API 令牌让外部系统按模块读写汐航数据。本页无需登录即可查阅。

前往 API 模块创建令牌
需要令牌才能调用。令牌在左侧菜单「API」模块中创建，可按「模块 → 权限」自由组合，明文只在创建页面显示，请立即保存到密码管理器。 令牌代表你本人，权限与你账号绑定，不要提交到代码仓库或发给他人。

基础地址

所有接口都以 /api/v1/vault 开头，拼接在汐航站点地址之后。例如本站的地址是：

http://42.193.159.241:9988/api/v1/vault

下文示例统一使用 $BASE 代表该前缀：

export BASE="http://42.193.159.241:9988/api/v1/vault"
export TOKEN="xh_vault_你的令牌"

鉴权

在请求头中携带 Bearer 令牌。缺少、格式错误、已吊销或已过期的令牌一律返回 401。

Authorization: Bearer xh_vault_xxxxxxxxxxxxxxxxxxxxxxxx

请求与响应均为 JSON，带 Content-Type: application/json。所有成功响应都包含 "ok": true。

权限范围

权限按「模块 → 模块下的权限」两级组织。创建令牌时自由勾选，遵循最小权限原则；权限不足时接口返回 403。

星钥库（vault）

权限含义可调用的接口
vault:read读取凭证记录（不含密码明文）列表、详情
vault:secret读取密码明文（高风险）读取密钥
vault:write新增、修改、删除凭证（高风险）创建、更新、删除

成本台账（ledger）

权限含义
ledger:read查看成本记录与项目
ledger:write新增、修改、删除成本记录
ledger:export导出成本数据

工作台（workspace）

权限含义
workspace:read读取工作台站点与偏好
workspace:write修改工作台站点与偏好

管理中枢（admin）· 仅管理员

权限含义授予者
admin:read读取全站用户、审计与设置仅管理员
admin:write修改用户、设置与站点分组仅管理员
管理员专属权限不会出现在普通用户的创建选项中。即使通过接口强行提交，服务端也会以 403 拒绝， 返回「这些权限仅管理员可授予」。

接口列表

GET /credentials vault:read

列出当前令牌所属账号的全部凭证。不包含密码明文。

curl -H "Authorization: Bearer $TOKEN" "$BASE/credentials"
{
  "ok": true,
  "total": 2,
  "credentials": [
    {
      "id": 12,
      "title": "生产环境数据库",
      "loginUsername": "app_ro",
      "category": "基础设施",
      "tags": ["线上", "只读"],
      "isFavorite": true,
      "url": "10.0.0.5",
      "notes": "仅内网访问",
      "createdAt": "2026-09-20T10:12:00.000Z",
      "updatedAt": "2026-09-25T03:40:00.000Z"
    }
  ]
}
GET /credentials/:id vault:read

读取单条凭证详情，同样不含密码明文。

curl -H "Authorization: Bearer $TOKEN" "$BASE/credentials/12"
GET /credentials/:id/secret vault:secret

解密并返回密码明文。请仅在确实需要时调用，避免写入日志。

curl -H "Authorization: Bearer $TOKEN" "$BASE/credentials/12/secret"
{ "ok": true, "secret": { "id": 12, "title": "生产环境数据库", "password": "******" } }
POST /credentials vault:write

新增一条凭证。title 与 password 必填，密码最少 8 位。成功返回 201。

curl -X POST -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "title": "测试环境 Redis",
    "loginUsername": "redis",
    "password": "Str0ng!Passw0rd",
    "category": "基础设施",
    "tags": ["测试"],
    "url": "10.0.0.9:6379",
    "notes": "由外部系统自动创建",
    "isFavorite": false
  }' \
  "$BASE/credentials"
PUT /credentials/:id vault:write

更新凭证。不传 password 即保留原密码，适合只改标题、标签等场景。

curl -X PUT -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{ "title": "测试环境 Redis（已迁移）", "notes": "10.0.0.10" }' \
  "$BASE/credentials/30"
DELETE /credentials/:id vault:write

删除凭证。成功返回 {"ok": true}，记录不存在返回 404。

curl -X DELETE -H "Authorization: Bearer $TOKEN" "$BASE/credentials/30"

字段说明

字段类型说明
titlestring凭证名称。创建时必填。
loginUsernamestring登录账号。
passwordstring密码明文，最少 8 位。写入后立即加密存储，读取时不会随列表返回。
categorystring所属项目或分类。
tagsstring[]标签，最多 12 个。
urlstring网址、IP 或内网地址。
notesstring备注。
isFavoriteboolean是否标记为常用。

错误码

状态码含义处理建议
400参数缺失或格式不正确检查请求体字段，注意密码长度与标签数量限制。
401令牌缺失、无效、已吊销或已过期确认 Authorization 头格式，或重新创建令牌。
403令牌权限不足该操作需要的权限未授予，请重建令牌并勾选对应权限。
404记录不存在记录的 ID 有误，或不属于该令牌的账号。
429请求过于频繁降低调用频率，见下方限流说明。

失败响应统一形如：

{ "ok": false, "message": "记录不存在。" }

限流与安全

  • 常规接口每个令牌 120 次/分钟；读取密码明文接口 60 次/分钟。
  • 令牌仅保存摘要，服务端无法还原明文。遗失请直接吊销并新建。
  • 令牌只能访问创建者本人的凭证，账号之间互相隔离。
  • 建议为每个外部系统单独建令牌，并只勾选该场景所需的最小权限。
  • 把令牌放进环境变量或密钥管理服务，不要硬编码到前端代码或公开仓库。
