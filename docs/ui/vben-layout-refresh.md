# 汐航内部布局更新

参考 Vue Vben Admin main 分支的 dashboard/workspace 与 basic/header 源码，采用侧栏、顶部工具栏、页面标签、工作区的布局结构。汐航继续使用现有 Vite 多页面应用，不迁移认证或后端框架。

覆盖工作台、星钥库、管理中枢、成本台账。新增 `frontend/src/shell.js` 和仅作用于 `.vben-shell.console-page` 的 `frontend/src/styles/admin-layout.css`；登录页及认证请求代码在本轮保持原样。

工作台采用应用目录与快捷操作双栏，基础设施分组使用较弱的视觉强调。星钥库改为列表与编辑区双栏，并用实际项目分类数和常用记录数替代未实现的到期指标。移动端使用可关闭的导航抽屉，支持 Escape、遮罩关闭和侧栏隐藏时的 inert 状态。

验证：12 项现有登录回跳、台账和权限回归测试通过。服务器无界面浏览器使用模拟 API 数据验证四页在 1440px 与 390px 下的布局、应用加载和搜索、管理分类切换、记账弹窗、普通成员入口隐藏及应用接口错误提示；同一组运行时检查在正式 9988 部署后通过。浏览器测试不创建生产账号、不写生产业务数据、不代表真实钉钉扫码授权验证。

发布：将已验证候选构建的资源先复制到 dist/assets，再逐页替换 HTML；保留旧哈希资源以兼容已有页面。发布前构建备份位于 `/tmp/tidesail-pre-vben-dist.tar.gz`，源码备份位于 `/tmp/tidesail-before-vben-layout.tar.gz`。生产 API 未因本次布局改动重启。
