# 工作空间导航去重设计

## 目标

保留工作区顶部导航，同时移除页面主体重复的标题说明区，降低视觉噪声和用户对当前所在位置的辨识成本。

## 现状与根因

顶部 `.workspace-header` 和 `.workspace-tabs` 是用户认可的工作区导航，应当保留。重复来自各业务页面自己的 `.console-topbar`：它再次显示当前页面标题和说明，而顶部面包屑及页签已经提供了当前页面上下文。共享样式还把粒子画布放在 `z-index:0`，并把整个内容容器放在 `z-index:1`，落叶容易被内容层盖住。

## 设计

- 左侧 `.side-nav`、顶部工作区面包屑和 `.workspace-tabs` 全部保留，继续承担页面切换、当前项高亮和位置提示。
- 页面主体 `.console-topbar.page-heading` 在共享壳层中隐藏，避免再次显示当前页面标题和说明；其 DOM 仍保留，供脚本读取动态标题和挂载外观面板。
- 工作台首页的欢迎区、统计区和应用内容继续保留，不受主体标题隐藏规则影响。
- `.console-main` 继续为“顶部栏 + 横向页签”预留空间；移动端同步保持原来的间距。
- 季节粒子作为全局环境层置于页面背景之上、页面实际内容之下；其 `pointer-events` 保持为 `none`，不会影响操作。

## 约束

- 不改动业务数据、接口、登录权限和 Toast/粒子层逻辑。
- 四个已认证页面共用同一套壳层规则。
- 保留侧栏收起、移动端抽屉、键盘 Escape 和当前项高亮行为。
- 顶部栏必须在桌面端和移动端保持可用，不能出现空白占位。
- 层级顺序固定为“背景 < 落叶 < 页面内容 < 顶栏/侧栏 < Toast/弹窗”。

## 验证标准

- 四个页面 DOM 中都保留 `.workspace-tabs`，且顶部页签可切换四个页面。
- 页面主体 `.console-topbar.page-heading` 不可见，星钥库等页面不再重复显示标题说明。
- 工作台欢迎区仍可见，桌面端和移动端顶部布局无横向溢出。
- 落叶在四个页面可见，且不覆盖文字/按钮的视觉层，也不拦截点击。
- 现有测试、语法检查和前端构建继续通过。
